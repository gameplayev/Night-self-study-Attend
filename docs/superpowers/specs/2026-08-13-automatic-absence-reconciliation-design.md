# 관리자 첫 접속 자동 결석 정산 설계

## 목표

- 출석 대상일에 출결 기록이 없는 학생을 다음 관리자 접속 시 자동으로 결석 처리한다.
- 관리자가 며칠 접속하지 않아도 마지막 정산 다음 날부터 어제까지 빠짐없이 소급한다.
- 학생별 출석 요일을 따르고 토요일과 일요일은 항상 제외한다.
- 자동 결석을 화면 계산으로만 보여주지 않고 `attendance_records`에 영구 기록한다.

## 선택한 방식

교사 계정의 `GET /api/attendance`가 출결 기록을 읽기 전에 Supabase 정산 함수를 한 번 호출한다. 정산 함수는 DB 트랜잭션 안에서 마지막 처리일 다음 날부터 한국 시간 기준 어제까지 처리하고, 성공한 뒤에만 마지막 처리일을 갱신한다.

별도 자정 크론은 두지 않는다. 사용자가 승인한 "다음날 관리자 첫 접속" 요구를 만족하면서 배포 설정과 비밀 키를 추가하지 않는 가장 작은 방식이다.

## 데이터 모델

### 학생 출석 시작일

`students.attendance_started_on date not null`을 추가한다. 기본값은 한국 시간 기준 현재 날짜다. 기존 학생은 마이그레이션 적용일을 시작일로 삼아 과거 전체가 갑자기 결석 처리되지 않게 한다. 새 학생도 등록일 이전 날짜는 정산 대상이 아니다.

### 정산 상태

`attendance_reconciliation_state`에 단일 행과 `last_processed_date`를 둔다. 최초 값은 마이그레이션 적용일의 전날이다. 따라서 기능 적용 전 날짜는 자동 소급하지 않고, 적용 이후 미처리 날짜만 정산한다.

## DB 정산 함수

정산 함수는 다음 순서로 동작한다.

1. 한국 시간 기준 어제를 정산 종료일로 구한다.
2. 트랜잭션 범위 advisory lock을 획득해 동시 관리자 요청을 직렬화한다.
3. `last_processed_date + 1`부터 어제까지 날짜를 생성한다.
4. 토·일을 제외하고, 각 날짜가 학생의 `attendance_weekdays`에 포함되며 `attendance_started_on` 이후인지 확인한다.
5. 해당 학생·날짜에 `check_in`, `check_out`, `present`, `absent` 중 어떤 기록도 없을 때만 `absent` 기록을 넣는다.
6. 자동 기록에는 `device_id='system-auto'`, `device_label='시스템 자동 결석'`을 저장한다.
7. 모든 INSERT가 성공한 뒤 `last_processed_date`를 어제로 갱신한다.

함수 전체가 한 트랜잭션이므로 중간 실패 시 결석 기록과 처리일 갱신이 함께 롤백된다. 동시에 여러 관리자가 접속해도 lock 이후 최신 처리일을 다시 확인하므로 중복 생성하지 않는다.

## 날짜 예시

- 목요일 첫 접속: 수요일까지만 정산하고 당일 미출석은 아직 결석으로 확정하지 않는다.
- 월요일 첫 접속: 마지막 처리일 이후 금·토·일을 확인한다. 금요일 대상 학생만 결석 처리하고 토·일은 건너뛴다.
- 학생이 화·목만 출석하는 경우: 미처리 기간의 화·목만 검사한다.
- 그날 출석 후 퇴실한 학생: 기존 기록이 있으므로 자동 결석을 추가하지 않는다.

## 서버 연동과 오류 처리

- 교사 계정의 출결 조회에서만 정산 함수를 호출한다.
- 학생 계정의 출결 조회는 다른 학생 데이터를 변경하지 않는다.
- 정산 실패 시 오래된 명단을 정상 응답으로 위장하지 않고 기존 DB 오류 흐름으로 요청을 실패시킨다.
- 정산 후 같은 요청에서 새 결석 기록까지 포함한 전체 출결 기록을 반환한다.

## 검증

- 금요일 미출석 후 월요일 첫 관리자 조회에서 금요일 결석 기록이 생성되는지 확인한다.
- 토·일에는 자동 결석이 생성되지 않는지 확인한다.
- 학생의 비대상 요일과 등록일 이전 날짜가 제외되는지 확인한다.
- 기존 출결 기록이 있으면 자동 결석이 추가되지 않는지 확인한다.
- 같은 날짜를 반복 또는 동시에 정산해도 결석이 중복되지 않는지 확인한다.
- 실패 시 처리일만 앞서가지 않고 전체 트랜잭션이 롤백되는지 확인한다.
- 전체 Jest, TypeScript 검사, Next.js 프로덕션 빌드를 실행한다.

## 제외 범위

- 공휴일·재량휴업일·학교 행사일 예외 캘린더
- 자정에 실행되는 Vercel Cron
- 날짜별 일회성 학생 출석 예외

현재는 학생별 월~금 설정만 출석 대상일로 판단한다. 공휴일 제외가 필요해지면 별도 학교 휴일 테이블을 추가한다.
