# 학생별 야자 출석 요일 설계

## 목표

- 관리자가 학생별로 월~금 중 야자 출석 대상 요일을 지정한다.
- 학생 명단에서 `결석` 열 옆에 `출석 요일` 열을 둔다.
- 토요일과 일요일은 어떤 학생도 결석으로 집계하지 않는다.
- 기존 학생과 새 학생은 기본적으로 월~금 전체를 출석 대상 요일로 가진다.

## 선택한 방식

학생의 기존 수정 흐름에 출석 요일을 포함한다. 평소에는 `월·수·금`처럼 요약해서 보여주고, 해당 학생의 `수정` 버튼을 누르면 같은 열에서 월~금 체크박스를 편집한다. 기존 `저장` 버튼이 학생 정보와 요일을 한 번에 저장한다.

별도 모달이나 전교생 공통 설정은 두지 않는다. 학생별 값이 필요한 요구와 맞지 않고, 기존 학생 수정 API를 재사용하는 편이 파일 수와 실패 지점을 줄인다.

## 데이터와 API

- `students.attendance_weekdays integer[] not null default '{1,2,3,4,5}'`를 추가한다.
- DB 제약으로 값이 월~금 `1..5` 안에 있고 하나 이상인지 확인한다.
- 학생 목록·생성·수정 응답에 `attendanceWeekdays`를 포함한다.
- 학생 수정 요청은 기존 학번·이름·좌석과 `attendanceWeekdays`를 함께 저장한다.
- 기존 전교생 공통 `attendance_settings`와 관련 API/UI는 제거한다.

## 결석 판정

결석 횟수를 계산할 때 날짜의 요일을 한국 학교 날짜 키에서 구한다. 토·일이면 즉시 제외하고, 평일이어도 해당 학생의 `attendanceWeekdays`에 없으면 제외한다. 대상 요일인 과거 날짜만 기존 일일 출결 결과로 결석 여부를 계산한다.

날짜별 출결표에서도 토·일 또는 학생의 비대상 요일은 결석으로 표시하지 않고 `비대상`으로 표시한다. 관리자가 비대상 날짜를 결석 처리하는 버튼도 노출하지 않는다.

## UI와 오류 처리

- 기존 Tailwind 색상·간격·표 스타일을 그대로 복사해 새 디자인 체계를 만들지 않는다.
- 월~금 체크박스는 키보드로 조작 가능하고 각 입력에 요일 이름을 제공한다.
- 최소 한 요일은 반드시 선택해야 하며, 비어 있으면 저장하지 않고 행 안에 오류를 표시한다.
- 서버도 동일한 검증을 수행해 잘못된 직접 API 요청을 거부한다.

## 검증

- 월·수·금 학생이 화요일 미출석이어도 결석 횟수가 늘지 않는지 확인한다.
- 토·일은 모든 학생의 결석 횟수와 날짜별 결석 표시에서 제외되는지 확인한다.
- 관리자 학생 행에서 요일 변경 후 저장 요청과 화면 요약이 갱신되는지 확인한다.
- 잘못된 요일 배열과 빈 배열을 서버 경계에서 거부하는지 확인한다.
- 전체 Jest, TypeScript 빌드, 실제 관리자 화면의 데스크톱·태블릿·모바일 가로 스크롤을 확인한다.

## 제외 범위

- 공휴일·학교 행사일 예외 캘린더
- 날짜별 일회성 학생 예외
- 주 단위로 달라지는 교대 스케줄

필요해질 때 별도 일정 예외 테이블로 확장한다.
